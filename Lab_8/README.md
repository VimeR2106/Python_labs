## 2. Кодирование «волхо»

\[
\begin{aligned}
Low_{new}  &= Low_{old} + (High_{old} - Low_{old}) \cdot Low_{symbol} \\
High_{new} &= Low_{old} + (High_{old} - Low_{old}) \cdot High_{symbol}
\end{aligned}
\]

**в** → \(y_{в} = [0.000000,\ 0.242400]\)

**о** → \(y_{во}\):
- Low = \(0 + 0.2424 \cdot 0.5454 = 0.132205\)
- High = \(0 + 0.2424 \cdot 0.6666 = 0.161584\)
- \([0.132205,\ 0.161584]\)

**л** → \(y_{вол}\):
- Low = \(0.132205 + 0.029379 \cdot 0.2424 = 0.139326\)
- High = \(0.132205 + 0.029379 \cdot 0.3939 = 0.143777\)
- \([0.139326,\ 0.143777]\)

**х** → \(y_{волх}\):
- Low = \(0.139326 + 0.004451 \cdot 0.6666 = 0.142293\)
- High = \(0.139326 + 0.004451 \cdot 0.7878 = 0.142833\)
- \([0.142293,\ 0.142833]\)

**о** → \(y_{волхо}\):
- Low = \(0.142293 + 0.000540 \cdot 0.5454 = 0.142588\)
- High = \(0.142293 + 0.000540 \cdot 0.6666 = 0.142653\)
- **итоговый интервал \([0.142588,\ 0.142653]\)**

**Код:** любое число из интервала, например **`code = 0.14262`**

## 3. Декодирование `code = 0.14262`

\[
y_{next} = \frac{y - Low_{symbol}}{High_{symbol} - Low_{symbol}}
\]

1. \(0.14262 \in [0.0000,\ 0.2424]\) → **в**  
   \(y = 0.14262 / 0.2424 = 0.588366\)

2. \(0.588366 \in [0.5454,\ 0.6666]\) → **о**  
   \(y = (0.588366 - 0.5454) / 0.1212 = 0.354508\)

3. \(0.354508 \in [0.2424,\ 0.3939]\) → **л**  
   \(y = (0.354508 - 0.2424) / 0.1515 = 0.739985\)

4. \(0.739985 \in [0.6666,\ 0.7878]\) → **х**  
   \(y = (0.739985 - 0.6666) / 0.1212 = 0.605487\)

5. \(0.605487 \in [0.5454,\ 0.6666]\) → **о**

**Результат:** `волхо` — совпадает с исходным сообщением.
